Configuración / Setup

Este portal aún no está conectado. Sigue estos pasos (solo una vez):

  1. En supabase.com crea un proyecto (gratis).
  2. Menú SQL Editor → New query: pega el código de abajo → Run.
  3. Project Settings → API: copia Project URL y la llave anon public (NUNCA la service_role).
  4. Abre este mismo archivo en un editor de texto, busca PEGA AQUI TUS DATOS y reemplaza SUPABASE_URL y SUPABASE_ANON_KEY.
  5. Supabase → Authentication → URL Configuration: en Site URL pon la dirección final del portal.
  6. Sube este archivo a Vercel (renómbralo index.html).
  7. Crea tu cuenta en el portal y corre en SQL Editor: update public.profiles set role='admin', status='approved' where email='TU-CORREO'; — luego cierra sesión y entra otra vez.
